## ▶️ Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en un navegador.
4. Para modificar el diseño, edita el archivo `styles.css`.

También puedes utilizar **Visual Studio Code** y la extensión **Live Server** para visualizar los cambios en tiempo real.
